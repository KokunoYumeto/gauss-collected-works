\par\noindent\hspace*{\parindent}[Sei \(X\) eine Funktion des Winkels \(x\) von der Form
\[
\begin{aligned} X &= \alpha_0 + \alpha_1\cos x + \alpha_2\cos 2x + \alpha_3\cos 3x + \cdots \\ &\quad + \beta_1\sin x + \beta_2\sin 2x + \beta_3\sin 3x + \cdots \end{aligned}
\]
und seien für \(\mu\) äquidistante Werte von \(x\), nämlich \(x=0, a, 2a, 3a, \ldots (\mu-1)a\), die entsprechenden Werte von \(X\), nämlich \(X = A_0, A_1, A_2, \ldots A_{\mu-1}\), gegeben. Ferner sei \(\mu a = 360^{0}\), sodass die \(\mu\) Werte von \(x\) den gesamten Kreisumfang in \(\mu\) gleiche Teile teilen. Nimmt man außerdem an, dass \(\mu\) eine gerade Zahl ist, so kann man \(\mu = 2m\) setzen und nach Art.\ 22 der Theoria interpolationis methodo nova tractata (Band III, Seite 298) die \(2m\) Koeffizienten \(\alpha_0, \alpha_1, \alpha_2 \ldots \alpha_m, \beta_1, \beta_2 \ldots \beta_{m-1}\) bestimmen. So erhält man eine angenäherte Darstellung der Funktion \(X\).
\par\noindent\hspace*{\parindent}Aus dem in der genannten Abhandlung (Band III, Seite 299) hergeleiteten und dort mit \(T\) bezeichneten Ausdruck erhält man die folgenden Gleichungen zur Bestimmung der Koeffizienten:
\[
\begin{aligned}
m\alpha_n &= A_0 + A_1\cos na + A_2\cos 2na + \cdots + A_{\mu-1}\cos(\mu-1)na\\
m\beta_n &= A_1\sin na + A_2\sin 2na + \cdots + A_{\mu-1}\sin(\mu-1)na,
\end{aligned}
\]
wobei der Index \(n\) die Werte \(1, 2 \ldots m-1\) annimmt, während
\[
\begin{aligned}
\mu\alpha_0 &= A_0 + A_1 + A_2 + A_3 + \cdots + A_{\mu-1}\\
\mu\alpha_m &= A_0 - A_1 + A_2 - A_3 + \cdots - A_{\mu-1}
\end{aligned}
\]
gelten.
\par\noindent\hspace*{\parindent}Diese Gleichungen lassen sich noch erheblich vereinfachen:
\par\noindent\hspace*{\parindent}Es gilt \(\cos(\mu-1)na = \cos na\) usw., \(\sin(\mu-1)na = -\sin na\) usw., sodass man schreiben kann:
\[
\begin{aligned}
m\alpha_n &= \tfrac12 B_0 + B_1\cos na + B_2\cos 2na + \cdots + B_{\frac{\mu}{2}-1}\cos\Big(\frac{\mu}{2}-1\Big)na + \tfrac12 B_{\frac{\mu}{2}}\cos\frac{\mu}{2}na\\
m\beta_n &= C_1\sin na + C_2\sin 2na + \cdots + C_{\frac{\mu}{2}-1}\sin\Big(\frac{\mu}{2}-1\Big)na,
\end{aligned}
\]
wo
\[
\begin{gathered}
B_0 = 2A_0,\quad B_1 = A_1+A_{\mu-1},\quad B_2 = A_2+A_{\mu-2},\quad \ldots\quad B_{\frac{\mu}{2}-1} = A_{\frac{\mu}{2}-1}+A_{\frac{\mu}{2}+1},\quad B_{\frac{\mu}{2}} = 2A_{\frac{\mu}{2}}\\[4pt]
C_1 = A_1-A_{\mu-1},\quad C_2 = A_2-A_{\mu-2},\quad \ldots\quad C_{\frac{\mu}{2}-1} = A_{\frac{\mu}{2}-1}-A_{\frac{\mu}{2}+1}.
\end{gathered}
\]
\par\noindent\hspace*{\parindent}Weiter gilt
\[
\begin{gathered}
\cos\Big(\frac{\mu}{2}-1\Big)na = \mp\cos na \quad \text{usw.}\\[4pt]
\sin\Big(\frac{\mu}{2}-1\Big)na = \pm\sin na \quad \text{usw.,}
\end{gathered}
\]
wobei das obere oder untere Vorzeichen gilt, je nachdem, ob \(n\) ungerade oder gerade ist.
\SourceLeaf{498}
\par\noindent\hspace*{\parindent}Sind also \textls[140]{sowohl \(n\) als auch \(\frac{\mu}{2}=m\) ungerade}, so erhält man
\[
\tag*{1)}
\begin{array}{l}
m\alpha_n = \tfrac{1}{2}D_0 + D_1\cos na + D_2\cos 2na + \cdots + D_{\frac{\mu}{4}-\frac{1}{2}}\cos\left(\frac{\mu}{4}-\frac{1}{2}\right)na \\[4pt]
m\beta_n = \phantom{{}={}} E_1\sin na + E_2\sin 2na + \cdots + E_{\frac{\mu}{4}-\frac{1}{2}}\sin\left(\frac{\mu}{4}-\frac{1}{2}\right)na,
\end{array}
\]
wo
\[
\begin{gathered}
D_0 = B_0 - B_{\frac{\mu}{2}}, \quad D_1 = B_1 - B_{\frac{\mu}{2}-1}, \quad D_2 = B_2 - B_{\frac{\mu}{2}-2}, \quad \ldots \quad D_{\frac{\mu}{4}-\frac{1}{2}} = B_{\frac{\mu}{4}-\frac{1}{2}} - B_{\frac{\mu}{4}+\frac{1}{2}}\\[4pt]
E_1 = C_1 + C_{\frac{\mu}{2}-1}, \quad E_2 = C_2 + C_{\frac{\mu}{2}-2}, \quad \ldots \quad E_{\frac{\mu}{4}-\frac{1}{2}} = C_{\frac{\mu}{4}-\frac{1}{2}} + C_{\frac{\mu}{4}+\frac{1}{2}}.
\end{gathered}
\]
\par\noindent\hspace*{\parindent}Ist \textls[140]{\(n\) ungerade und \(\frac{\mu}{2}=m\) gerade}, so erhält man:
\[
\tag*{2)}
\begin{array}{l}

\[
\begin{gathered}

E_1 = C_1 + C_{\frac{\mu}{2}-1}, \quad \ldots \quad E_{\frac{\mu}{4}-1} = C_{\frac{\mu}{4}-1} + C_{\frac{\mu}{4}+1}, \quad E_{\frac{\mu}{4}} = 2C_{\frac{\mu}{4}}.
\end{gathered}
\]

wo

\par\noindent\hspace*{\parindent}Bei der Anwendung auf die Berechnung der Pallasstörungen wird \(\frac{\mu}{2}=m\) stets als gerade angenommen. Deshalb werden nur die beiden Formeln 2 und 4 weiterentwickelt:

\frac{m}{2}(\beta_n-\beta_{m-n}) = \phantom{{}={}} E_2\sin 2na + E_4\sin 4na + \cdots + E_{\frac{\mu}{4}-1}\sin\left(\frac{\mu}{4}-1\right)na,

\]

\[

wenn \(\frac{n}{4}\) und \(\frac{\mu}{8}\) beide gerade sind:
\[
\tag*{14)}
\begin{array}{l}
m\alpha_n = \tfrac{1}{2}P_0 + P_1\cos na + P_2\cos 2na + \cdots + P_{\frac{\mu}{16}-1}\cos\left(\frac{\mu}{16}-1\right)na + \tfrac{1}{2}P_{\frac{\mu}{16}}\cos\frac{\mu}{16}na \\[4pt]
m\beta_n = \phantom{{}={}} Q_1\sin na + Q_2\sin 2na + \cdots + Q_{\frac{\mu}{16}-1}\sin\left(\frac{\mu}{16}-1\right)na,
\end{array}
\]
wo
\[
\begin{gathered}
P_0 = K_0 + K_{\frac{\mu}{8}}, \quad P_1 = K_1 + K_{\frac{\mu}{8}-1}, \quad \ldots \quad P_{\frac{\mu}{16}-1} = K_{\frac{\mu}{16}-1} + K_{\frac{\mu}{16}+1}, \quad P_{\frac{\mu}{16}} = 2K_{\frac{\mu}{16}}\\[4pt]
Q_1 = L_1 - L_{\frac{\mu}{8}-1}, \quad \ldots \quad Q_{\frac{\mu}{16}-1} = L_{\frac{\mu}{16}-1} - L_{\frac{\mu}{16}+1}.
\end{gathered}
\]

Weitere Umformungen werden hier weggelassen, weil sie ohne Weiteres einleuchten und man für den vorliegenden Zweck nicht weitergehen muss.]
