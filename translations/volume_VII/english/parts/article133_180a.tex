Since the cosines of the angles $f,f',f''$, like the quantities $\eta,\eta''$, differ from unity by a
quantity of the second order, an error of the fourth order is incurred if we replace $\dfrac{n+n''}{n'}$ with
the approximate value $1+\dfrac{\theta\theta''}{2rr'r''}$. Therefore, if in place of the equation in Article 114 we use
\[
a\delta'=b+\frac{c\theta+d\theta''}{\theta'}\left(1+\frac{\theta\theta''}{2rr'r''}\right)\mathpunct{\raisebox{.45ex}{,}}
\]
\hypertarget{native-180}{}the resulting error in the value of the distance $\delta'$ will be of the second order when the
outer observations are equidistant from the middle one and of the first order in the other
cases. This new form of the equation is unsuitable for determining $\delta'$, however, because it
contains the still unknown quantities $r,r',r''$.
\par
In general, the quantities $\dfrac{r}{r'}\mathpunct{\raisebox{.45ex}{,}}\;\dfrac{r''}{r'}$ differ from unity by quantities of the first order, and the
same is true of the product $\dfrac{rr''}{r'r'}$. In the special case already mentioned several times, it is
easy to see that this product differs from unity by a quantity of the second order only.
Moreover, whenever the orbit is an ellipse of small eccentricity, so that the eccentricity can
be regarded as a quantity of the first order, the difference of $\dfrac{rr''}{r'r'}$ from unity can be
assigned to an order one step higher still. The error thus clearly remains of the same order as
before if we replace $\dfrac{\theta\theta''}{2rr'r''}$ in our equation with $\dfrac{\theta\theta''}{2r'^3}\mathpunct{\raisebox{.45ex}{,}}$ giving it the following form
\[
a\delta'=b+\frac{c\theta+d\theta''}{\theta'}\left(1+\frac{\theta\theta''}{2r'^3}\right)\mathpunct{\cdot}
\]
This equation still contains the unknown quantity $r'$. It can clearly be eliminated, since it
depends only on $\delta'$ and known quantities. If the equation were then arranged in proper order,
it would be of the \textit{eighth} degree.
