\noindent Here we must have the coefficient of \(\cos M,\ =-e\),
so that \(\eta\eta=1-\tfrac32nn\) or \(\eta=1-\tfrac34nn\).
This value of \(\eta\) still differs considerably
from the true value, for reasons that will become apparent below. --- Furthermore,
we may set \(\mathit{Const.}\cos(v+\mathit{Const.})=0\) here,
since this integral equation already contains 2 arbitrary quantities
(\(e\) and \(M-\eta v\)), which can of course be determined
so as to represent the initial state exactly. If we retained the term
\(\mathit{Const.}\cos(v+\mathit{Const.})\), then at the second
refinement circular arcs would enter the value of \(p\), and at the
3\textsuperscript{rd} even squares of circular arcs, and~so~on, although
on closer examination these arcs in fact again give only periodic
equations and yield the same result as the assumption \(\mathit{Const.}=0\).
The preceding remark makes this expansion unnecessary. ---
