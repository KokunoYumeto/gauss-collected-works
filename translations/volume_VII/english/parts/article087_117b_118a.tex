II. Let $\log r=0{,}428\,2792$, $\log r'=0{,}406\,2033$, $\Delta=62^0\,55'\,16''{,}64$, and $t=259{,}88477$ days. This gives $\omega=-1^0\,27'\,20''{,}14$, $\log a=9{,}748\,2348$, $\beta=0{,}045\,3511\,4$, $\gamma=1{,}681\,121$, $\log\BareRoot{p}=0{,}219\,8013$, and $\log p=0{,}439\,6026$. The last value is $211$ units too small in the seventh decimal place. The true value in this example is $0{,}439\,6237$. Formula VI gives $0{,}436\,8730$, formula VII gives $0{,}415\,9824$, and finally formula VIII gives $0{,}405\,1103$. The last two values here differ so much from the true value that they cannot even serve as approximations.
